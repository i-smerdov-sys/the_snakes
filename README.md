
# Изгиб Питона

«Изгиб Питона» — простая игра «Змейка», написанная на Python
с использованием библиотеки Pygame.

## Запуск проекта

1. Установите Python.
2. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Запустите игру:

   ```bash
   python the_snake.py
   ```

## Управление

- Стрелка вверх — движение вверх.
- Стрелка вниз — движение вниз.
- Стрелка влево — движение влево.
- Стрелка вправо — движение вправо.

## Правила игры

- Змейка перемещается по игровому полю.
- При поедании яблока змейка увеличивается.
- При столкновении с собственным телом змейка начинает игру заново.
- При выходе за границу поля змейка появляется с противоположной стороны.

## Используемые технологии

- Python
- Pygame-ce
